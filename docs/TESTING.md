# Проверка приложения

## Автоматические проверки

Frontend:

```powershell
cd frontend
npm ci
npm test
npm run test:coverage
npm run build
npm run lint
```

Backend (из корня репозитория):

```powershell
backend\.venv\Scripts\python.exe -m pytest backend
```

## Полный стек: Playwright

```powershell
cd frontend
npx playwright install chromium
npm run test:e2e
```

Перед запуском освободите порты 8000 и 5173. Конфигурация сама запускает
настоящий Django, отдельный процесс обработки PDF и production-сборку frontend
через Vite preview. HMR не используется. Существующие серверы
не переиспользуются, чтобы тест не попал в пользовательскую базу.

Каждый запуск получает случайный временный секрет Telegram-подписи и отдельные
SQLite, private storage и PDF job directory в `artifacts/e2e/<run-id>/`.
Постоянные тестовые пароли или токены не нужны. Каталог исключён из Git.
Тесты не удаляют пользовательские файлы или результаты прежних запусков.

Подменяется только мост Telegram-хоста: fixture генерирует initData с настоящим
HMAC, а приложение отправляет его в реальный backend для проверки. Успех API,
обработка PDF, файлы, прогресс и аннотации не подменяются ответами-заглушками.

Playwright сохраняет скриншот и trace при ошибке. HTML-отчёт:

```powershell
npx playwright show-report
```

## Границы автоматизации

Браузерный Chromium не подтверждает работу настоящего Telegram WebView.
Перед production-релизом обязательна отдельная проверка Telegram на iOS,
Android и Desktop: safe areas, клавиатура, сворачивание, пароль PDF,
жесты выделения, pinch-to-zoom, 3D и потеря графического контекста.

Локальный E2E использует SQLite и subprocess-обработку. Production PostgreSQL,
Redis/Celery, Nginx Range, HTTPS, Linux sandbox, backup/restore и обновление
проверяются отдельно в Docker/на staging VPS. Успех локального E2E не заменяет
эти испытания.

## Большие документы

В полном наборе есть тест с PDF ровно 100 000 000 байт. Он действительно
передаётся чанками в backend, обрабатывается и открывается через PDF.js.
Браузер должен получить частичные авторизованные ответы `206`, а не весь файл.
Этот тест помечен `@slow`, имеет timeout 240 секунд и отключённый trace,
чтобы не сохранять большие тела запросов в архиве.

Быстрый набор без него:

```powershell
npm run test:e2e -- --grep-invert '@slow'
```

Только проверка 100 МБ:

```powershell
npm run test:e2e -- --grep '@slow'
```

Большой fixture содержит настоящий трёхстраничный PDF и допустимые комментарии
до таблицы xref. Он проверяет границу размера и частичную загрузку; это не
измерение сложности 100-МБ скана или тяжёлой векторной книги.

Отдельный PDF на 250 страниц с портретными и альбомными страницами проверяет
переходы к далёким страницам и предел
в пять одновременно созданных canvas. Поиск, масштабирование, поворот,
перелистывание, reduced motion и немедленная кнопка «Назад» Telegram проходят
через настоящий интерфейс и backend.
