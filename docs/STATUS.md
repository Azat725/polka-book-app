# Состояние реализации — 8 ноября 2026

Приложение «Полка» реализовано локально. Пользовательские действия работают с
настоящим API, БД и файлами; демонстрационных книг и production-заглушек нет.
Публикация и подключение конкретного Telegram-бота пока не выполнены.

## Результаты проверок

Все приведённые результаты получены локально, а не в удалённом CI.

- Backend: **40 тестов прошли**, покрытие строк приложения `library` **93,82%**;
  проверка авторизации покрыта на 100%. Миграции исключены из метрики.
- Frontend: **49 тестов прошли**. Покрытие выбранных модулей API/upload/themes,
  геометрии и синхронизации — **92,62% строк**; это не покрытие всего frontend.
- Playwright: **17 сценариев прошли** с настоящими Django, обработчиком и PDF.js.
  Подменяется только Telegram host bridge с корректно подписанной тестовой initData.
- Пройдены полный цикл чтения/аннотаций/повторного входа, изоляция владельцев,
  коллекции/корзина, настройки/локализация, пагинация после 24 книг, парольный PDF,
  поиск/zoom/поворот, книга на 250 страниц и сохранение при немедленной кнопке «Назад».
- PDF ровно 100 000 000 байт загружен, обработан и открыт частичными ответами `206`.
  Это синтетический трёхстраничный fixture с допустимым заполнением, не benchmark
  сложного скана. Для длинной книги проверяется максимум пять активных canvas.
- Проверены совместимость без `Promise.withResolvers`/`Promise.try` в host realm
  и изменение viewport при повороте экрана.
- Пройдены ESLint, Prettier, TypeScript/Vite production build, Ruff, Django check,
  отсутствие незаписанных миграций и строгая генерация OpenAPI.
- Пройдены 2 теста генератора конфигурации, синтаксис shell-скриптов и разбор
  базового Compose вместе с bootstrap и AppArmor overrides.
- `npm audit` не обнаружил известных уязвимостей. Проверка закреплённых прямых
  Python-зависимостей также не обнаружила известных уязвимостей; полный аудит
  всех транзитивных Python-зависимостей этой проверкой не заявляется.

Журналы и снимки локальных прогонов находятся в исключённом из Git `artifacts/`.
Набор и способы повторения описаны в [TESTING.md](TESTING.md).

## Что ещё требует проверки окружения

Docker Engine в этой Windows-среде недоступен из-за неисправного WSL. Конфигурации
подготовлены и разобраны, но контейнеры здесь не запускались. До открытия доступа
нужно проверить на Linux/VPS PostgreSQL, Redis/Celery, sandbox namespace/LSM,
Nginx Range, сертификаты и восстановление настоящей резервной копии.

Настоящие Telegram iOS/Android/Desktop ещё не проверены. Требуются проверки
выделения текста, клавиатуры/safe areas, сворачивания, pinch, звука, GPU и памяти.
Число 50 пользователей — ориентир проектирования, а не измеренная нагрузочная ёмкость.

Для публичного запуска нужны настоящий токен бота, его username, домен и VPS.
Секреты вводятся через `scripts/configure.py`; общего пароля администратора нет.

## Границы поведения

- Пароль PDF вводится локально с предупреждением и не сохраняется. Для таких
  документов сервер может не получить число страниц и автоматическую обложку.
- OCR и платежи не добавлены. Скан без текста читается, но не получает текстовый поиск.
- Изгиб страницы начинается после отпускания жеста; он не следует непрерывно за
  пальцем. Короткий/отменённый жест сохраняет страницу, текущий переход можно прервать.
  При reduced motion или недоступном WebGL используется облегчённый переход.
- Нет гарантии сохранения самого последнего движения при принудительном убийстве
  WebView до завершения IndexedDB-транзакции. Ошибка локального сохранения показывается.
- Это изоляция личных библиотек, не end-to-end encryption. Доступ администратора
  инфраструктуры к диску технически сохраняется.

## Карта файлов и миграции

| Каталог/файл | Назначение |
|---|---|
| `backend/config/` | Настройки Django, маршруты, Celery, health |
| `backend/library/models.py` | Пользователи, книги, загрузки, прогресс, аннотации, настройки и аудит |
| `backend/library/*_views.py` | Версионированный API и проверки владельца |
| `backend/library/authentication.py`, `storage.py`, `processing.py` | Сессии, приватное хранение и обработка |
| `backend/library/admin*.py`, `management/commands/` | Admin, роли и служебные команды |
| `backend/tests/` | Backend/API/security проверки |
| `frontend/src/App.tsx`, `pages/`, `components/` | Экраны, навигация, библиотека и диалоги |
| `frontend/src/shared/` | API, загрузка, темы, RU/EN, Telegram и совместимость |
| `frontend/src/reader/` | PDF.js, страницы, текст/аннотации, поиск, синхронизация, перелистывание |
| `frontend/e2e/` | Полные пользовательские сценарии |
| `infra/`, `compose.yaml` | Контейнеры, offline sandbox, Nginx, политики, backup/restore |
| `scripts/` | Конфигурация, локальный запуск и изолированный E2E backend |
| `docs/openapi.yaml` | Сгенерированная схема API |

Миграции: `0001_initial` создаёт исходную схему, `0002_bookreadersettings` —
индивидуальные настройки читалки. При обновлении применяется обычный `migrate`;
генерация новых миграций на сервере не нужна.
